# Pembahasan jawaban di Riwayat Belajar

Baris Aktivitas terbaru dapat dibuka untuk melihat pembahasan jawaban yang salah. Kuis materi menyimpan nomor asli soal, teks soal, pilihan siswa, jawaban benar, dan pembahasan bersama nilai. Riwayat lama dan latihan harian yang hanya menyimpan nilai tetap tersedia. Pembahasan di riwayat menggunakan teks soal.

- Alur: GradeFourQuiz, SaveResult, API /hasil, dan ResultHistory.
- Terapkan migrasi Supabase 20261125220000 sebelum menerbitkan aplikasi. Klien lama tetap dapat memakai fungsi simpan dengan tujuh parameter.
- Login QA mencakup pembukaan baris yang memiliki rincian dan baris lama setelah halaman dimuat ulang.
