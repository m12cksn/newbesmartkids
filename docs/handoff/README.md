# Catatan serah terima per perubahan

Setiap PR menulis catatannya sendiri di folder ini, bukan menambah baris di tengah `docs/PROJECT_HANDOFF.md`. Dengan begitu dua sesi yang bekerja bersamaan tidak bentrok di file yang sama.

- Nama file: `YYYY-MM-DD-<nama-cabang>.md`, misalnya `2026-11-12-feat-grade-two-time.md`.
- Isi: cakupan, file penting, bukti validasi (perintah dan hasil), sisa masalah, status deploy.
- Setelah merge, catat nomor PR dan SHA merge di file yang sama lewat PR dokumentasi kecil. Jangan mengarang SHA.
- `docs/PROJECT_HANDOFF.md` berisi gambaran umum dan riwayat sampai 11 Nov 2026; tabel status di sana tidak perlu diedit untuk setiap bab.
